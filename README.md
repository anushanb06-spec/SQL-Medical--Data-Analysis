# Medical Data Analysis Using SQL

## Project Overview
This project analyzes medical data using SQL queries to
retrieve information about patients, doctors, and admissions.

## Tools Used
- MySQL Workbench
- MySQL

## Tables Used
- Patients
- Admission
- Doctors
- Province Names

## SQL Concepts
- SELECT statements
- WHERE conditions
- Data filtering
- Data retrieval
- SQL queries

## Objective
To practice SQL and extract meaningful information
from medical datasets.

## Conclusion
This project demonstrates the use of SQL queries
for medical data analysis.
